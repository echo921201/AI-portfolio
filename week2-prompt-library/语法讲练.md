# 模板：语法点讲练生成器

> 场景超市 ⑥　·　版本 v2

## 提示词

```
【角色】你是国际中文教育教师，擅长用简单的语言讲清语法。
【任务】为语法点"[语法点]"编写一份讲练材料，学生为[HSK等级]水平。
【要求】
1. 先讲后练，结构固定：一、结构公式 二、使用条件（3条以内）三、例句（5句）四、常见偏误（3组）五、练习（10题）六、答案
2. 结构公式用"[结构公式，如：A + 被 + (B) + 动词 + 其他成分]"的形式写出
3. 例句和练习只用[HSK等级]以内词汇，每句不超过15个字
4. 常见偏误每组写"✗ 错句 → ✓ 正句（一句原因）"
5. 练习题型配比：[题型配比，如：5道"把字句改被字句" + 3道"判断对错并改正" + 2道"看提示完成句子"]
6. 讲解语言用[HSK等级]以内的中文，不用语法术语堆砌
7. 只输出讲练材料本身，材料后面不要附总结
【示例】（偏误格式）
✗ 我的自行车被偷。 → ✓ 我的自行车被偷了。（动词后面要有"了"等其他成分）
```

## 适用说明

- **什么时候用**：专项讲一个语法点，比如把字句、被字句、"了"、补语，需要讲解和练习配套。
- **"先讲后练、例句不超纲"**：这是课件 P13 给的约束示例，对应要求 1 和要求 3。
- **换语法点**：改 `[语法点]`、`[结构公式]`，偏误示例也换成新语法点的。
- **使用提醒（重要）**：AI 编的例句和答案**必须逐句读一遍**。它会写出语法上勉强成立、但中国人不这么说的句子，偏误的"正句"有时本身也是错的。

## 最佳示例

> 实测：被字句，HSK4，第 2 轮。第 1 轮只返回了摘要，第 2 轮加了"只输出材料本身"。下面是节选，并标出了人工复核的结论。

**一、结构公式**
A + 被 + (B) + 动词 + 其他成分
例：我的钥匙被我妹妹拿了。

**二、使用条件**
1. 说话人想强调某样东西"被怎么样了"，特别是不好的事情
2. 可以说出做动作的人，也可以不说
3. 动词后面一定要加"了""过"等词语

**三、例句**
1. 我的书被我哥哥看了。
2. 这个苹果被猫吃掉了。
3. 玻璃杯被打破了。
4. 树被风吹掉了很多叶子。
5. 我的自行车被偷了。

**四、常见偏误**
- ✗ 我的书被看。 → ✓ 我的书被看了。（动词后面要有"了"等词语）
- ✗ 被我掉了钥匙。 → ✓ 我的钥匙被我掉了。（被字前面是受事者，不是施事者）
- ✗ 我被弟弟欺负。 → ✓ 我被弟弟欺负了。（动词后要加"了"）

**五、练习（节选）**
1. 妈妈洗了我的衣服。→ 我的衣服被妈妈洗了。
3. 小孩打破了花瓶。→ 花瓶被小孩打破了。
5. 雨淋湿了我的衣服。→ 我的衣服被雨淋湿了。
9. 这个窗户______（用"被"字句说破了）→ 这个窗户被风吹破了。

**人工复核（这一份问题最多，正好说明为什么要人工把关）**：
- ✓ 结构 6 部分齐全，题型配比 5+3+2 正确，例句都很短。
- ✗ 第二组偏误的"正句""我的钥匙被我掉了"本身是错句。"掉"不能直接带施事，应改为"我的钥匙被我弄丢了"。
- ✗ 练习第一部分的标题写成了"把'被'字句改为被字句"，应为"把字句改为被字句"。
- ✗ 练习 4 的答案"我的密码被我忘记了"、练习 10 的答案"我的手机被我丢了"，都是不自然的被字句。
- ✗ "欺负"可能超出 HSK4。

结论：这一版的结构可以直接用，但例句和答案要人工改。下一轮可以加一条："每个'✓正句'和每条答案，都要先确认是中国人日常会说的句子；如果被字句不自然，就换一个动词"。
