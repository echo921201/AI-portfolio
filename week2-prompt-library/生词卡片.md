# 模板：生词卡片制作器

> 作业 2 新增 ②（学科高频任务：制作可打印的生词卡）　·　版本 v2

## 提示词

```
【角色】你是国际中文教育教师，负责给[HSK等级]学生制作可打印的生词卡片。
【任务】为下列生词各做一张生词卡。
【要求】
1. 每张卡片固定7项：词语 / 拼音 / 词性 / 英文释义 / 常用搭配（2个）/ 例句（2句，附拼音）/ 易混词辨析（1组，没有就写"无"）
2. 拼音规则：除轻声外每个音节都必须标声调符号（如 决定 juédìng，不能写 juéding）；按词连写，词与词之间空一格（如 jiù huì，不能写 jiùhuì）；句首字母大写
3. 例句只用[HSK等级]以内词汇，每句不超过15个字，尽量和[课文名称]的内容有关；例句必须是中国人会说的自然句子，不能为了用上生词而硬凑
4. 易混词要选学生真的容易用混的近义词（如 坚持 vs 保持），不要选意思完全不同的词
5. 每张卡用Markdown二级标题"## 词语"开头，卡片之间用"---"分隔；不写卡片以外的任何说明文字
【示例】
## 放弃
- 拼音：fàngqì
- 词性：动词
- 英文释义：to give up
- 常用搭配：放弃机会；不要放弃
- 例句：① 他没有放弃。Tā méiyǒu fàngqì. ② 遇到困难不要放弃。Yùdào kùnnan bú yào fàngqì.
- 易混词辨析：放弃 vs 丢——"放弃"是自己决定不要了；"丢"是不小心找不到了。

【生词】[粘贴区：生词，用顿号隔开]
```

## 适用说明

- **什么时候用**：每课生词要做成卡片，打印出来发给学生，或者导入到记忆卡软件里。
- **换等级或课文**：改 `[HSK等级]`、`[课文名称]`，把生词粘到 `[粘贴区]`。
- **关键设计**：第 1 轮出现了几类问题：拼音漏标声调（juéding）、连写错误（jiùhuì）、例句不自然（"很感动人"），易混词也选成了"感动 vs 喜欢"这种意思根本不同的词。第 2 轮把拼音规则和易混词标准写成了明确的规则，并各配了正例和反例。
- **使用提醒**：拼音和例句要人工核对，尤其是轻声和变调。

## 最佳示例

> 实测：生词"商量、坚持、感动、决定"，HSK4，课文《愚公移山》，第 2 轮。输出如下，其中两张卡按人工复核结果做了修正，修正处加粗标出。

#### 坚持
- 拼音：jiānchí
- 词性：动词
- 英文释义：to persist, to insist on, to stick to
- 常用搭配：坚持下去；要坚持
- 例句：① 愚公坚持要搬山。Yúgōng jiānchí yào bān shān. ② 我们要坚持学中文。Wǒmen yào jiānchí xué **Zhōngwén**.
- 易混词辨析：坚持 vs 保持——"坚持"是继续不停地做一件事；"保持"是让某个现在的状态一直不改变。

---

#### 决定
- 拼音：juédìng
- 词性：动词/名词
- 英文释义：to decide; decision
- 常用搭配：决定去；做出决定
- 例句：① 愚公决定搬走这座山。Yúgōng juédìng bānzǒu zhè zuò shān. ② 他**做了一个新的决定**。**Tā zuòle yí gè xīn de juédìng.**
- 易混词辨析：决定 vs 确定——"决定"是做一个选择；"确定"是确认某个事情是不是真的。

**人工复核**：
- ✓ 第 1 轮的 juéding 已改成 juédìng。易混词"坚持 vs 保持""决定 vs 确定"都是真正的近义词，而且辨析准确。
- 原输出还有以下问题，没有放进上面的示例：
  - 汉字中间出现了多余的空格，如"搬 山"。
  - "和"的拼音写成 he，漏了声调，应为 hé。
  - "中文"拼成小写的 zhōngwén，应为 Zhōngwén。
  - "他决定了新的计划"搭配不当，已改成"他做了一个新的决定"。
  - "商量 vs 讨论"的辨析说"讨论也可以一个人单独想"，这是错的。
  - "商量"标成 shāngliàng，《现代汉语词典》标为 shāngliang（后一个字读轻声）。

  下一轮可以加："汉字之间不留空格；辨析写完后检查是否符合词典释义"。
