# 提示词迭代实录（第 2 周）

- **主攻场景**：① HSK 阅读理解题生成器（`出题.md`）
- **输入材料**：《愚公移山》白话版（代码包 `data/愚公移山.txt`【白话大意】）
- **目标**：出 5 道 HSK4 阅读理解题，可以直接放进教案和习题册
- **实测工具**：网页版 AI 对话工具。每轮都是新开对话、只发这一轮的提示词，避免受上一轮的影响
- **诊断框架**：课件 P10 "维度 → 病症 → 药方"
- **迭代轮数**：4 轮（R1–R3 是课堂工坊，R4 是作业 1 精读官方指南后补记的）

---

## R1　零约束（制造失控）

**提示词**
```
根据课文出5道题
[课文]
```

**AI 输出（节选）**
> **第一题：理解题**　愚公为什么决定要铲平大山？请用原文中的一句话来回答。
> **第三题：对比分析题**　比较智叟和愚公对移山这件事的态度有什么不同？各自代表了什么样的思想？
> **第五题：主旨题**　……请结合现实生活谈一谈你的看法。

**诊断**
| 维度 | 病症 |
|---|---|
| 题型结构 | ✕ 5 道全是简答题或论述题，没有选项，没法批改，也没法打印成习题 |
| 难度控制 | ✕ "对比分析""代表了什么样的思想"是给母语者的语文题，不是 HSK4 的难度 |
| 解析质量 | ✕ 没有答案，也没有解析 |
| 格式 | ✕ 没有固定格式，每次输出都不一样 |

**结论**：只说了"出题"，没说给谁出、出什么题型、用什么格式，AI 就按中小学语文阅读题的习惯来出。

## R2　加格式（+ 角色 + 题型 + 表格）

**改了什么**
- 加了角色："你是国际中文教育教师，熟悉 HSK 各级词汇与语法点"
- 限定题型："四选一单选题（A/B/C/D），附答案与解析"
- 限定格式："以 Markdown 表格输出，列为：题号 | 题干 | 选项 | 答案 | 解析"

**AI 输出（节选）**
| 题号 | 题干 | 选项 | 答案 | 解析 |
|---|---|---|---|---|
| 1 | 愚公决定铲平大山的主要原因是什么？ | A. 大山堵塞了出入的道路，给生活造成困扰 B. 他想要证明自己的力气很大 … | A | 课文开头明确说明"他苦于大山堵塞了出入的道路"…… |
| 2 | 对于愚公的计划，妻子的态度主要表现为什么？ | A. 完全支持和赞同 B. 提出疑问并指出计划的困难之处 C. 不置可否 D. 坚决反对 | B | …… |
| 4 | 智叟劝阻愚公时强调的是什么？ | … | B | …… |

**好在哪**：✓ 全部是四选一，✓ 表格格式统一，✓ 每题都有答案和解析。

**新病症**
| 维度 | 病症 |
|---|---|
| 题型结构 | ✕ 5 道全是细节查找题或人物态度题，一道词义题都没有，主旨也只是间接地考 |
| 难度控制 | ✕ 选项里出现了"不置可否""困扰""感染和激励"等超出 HSK4 的词 |
| 格式 | ✕ 表格前面多了一个标题和一句说明，正确选项还被加粗，等于泄露了答案 |

## R3　定标准（+ 配比 + 难度边界 + Few-shot）

**改了什么**（对应课件 P6 的"要求"和"示例"两根支柱）
- 配比：强制"2 道细节题 + 2 道词义题 + 1 道主旨题"，并在解析里标注考点
- 难度：题干和选项只用 HSK4 及以下的词，课文里的超纲词不能用在正确选项里
- 解析：必须"引用原文 + 点明考点"，禁止只写"见原文"
- 示例：贴了课件 P8 那张"标准输出"表（张先生 / 捷径），并补全了 4 个选项

**AI 输出（节选）**
| 题号 | 题干 | 选项 | 答案 | 解析（引用原文依据） |
|---|---|---|---|---|
| 1 | 愚公为什么决定和家人一起挖山？ | A. 因为大山很高很美 B. 因为大山挡住了进出的道路 C. … D. … | B | 原文"他苦于大山堵塞了出入的道路，便召集家人商量"……考点：细节题 |
| 3 | "苦于"在这里的意思是什么？ | A. 正在做很苦的工作 B. 肚子很饿难受 C. 对某种情况感到困扰和不满 D. 没有足够的能力 | C | …考点：词义推断 |
| 5 | 这个故事想要告诉我们什么？ | A. 所有的山都是可以平的 B. 要一直坚持做一件事就能成功 C. … D. … | B | 原文通过……"子子孙孙无穷无尽……还愁挖不平吗"……考点：篇章主旨 |

**好在哪**
- ✓ 配比完全正确：第 1、2 题是细节题，第 3、4 题是词义题，第 5 题是主旨题。
- ✓ 每条解析都引用了原文，并标了考点。
- ✓ 选项的难度明显下降，而且干扰项设计合理（B"肚子很饿"是望文生义型的干扰项）。

**残留问题**
- ✕ 表格后面多了一段"已按要求生成 5 道题目……"的自我总结，粘进教案时还得手动删掉。
- ✕ 正确选项 C"对某种情况感到困扰和不满"里的"困扰"本身就超出 HSK4，没有完全遵守难度约束。
- ⚠ 风险：提示词里的示例课文（张先生）和真正要出题的课文都用普通文字堆在一起，AI 分不清哪段是材料、哪段是示范。换一篇短课文时，它就可能从示例里取材出题。

## R4　结构化分区（作业 1：落地 OpenAI 提示工程指南的技巧）

**精读来源**：OpenAI 官方《Prompt engineering》指南（developers.openai.com/api/docs/guides/prompt-engineering）。

**精读要点**（和本课"四件套"对照）
- `developer`（开发者）指令的优先级高于 `user`（用户）消息。开发者消息像"函数定义"，写规则；用户消息像"函数参数"，放每次要换的内容。对应到模板：固定的规则部分相当于函数定义，`[粘贴区]` 相当于参数。
- Few-shot：模型会从示例中"领会"模式，示例要覆盖多样的输入。这和课件 P8"你示范什么，它就交付什么"是一个意思。
- 把提示词当代码来管理，改了就要测试或评测。这就是 prompt-library + 迭代实录 + Git 提交历史在做的事。

**落地的技巧**：指南的"Message formatting with Markdown and XML"一节建议，提示词按 **Identity（身份）→ Instructions（指令）→ Examples（示例）→ Context（上下文）** 的顺序组织。用 Markdown 标题分出层级，用 **XML 标签**标明"一段材料从哪里开始、到哪里结束"，上下文放在最后。

**改了什么**
- 按"# 身份 / # 指令 / # 示例 / # 上下文"四段重排了提示词
- 示例用 `<示例 说明="仅示范格式与解析写法，不是出题材料">` 包起来，课文用 `<课文 等级="HSK4">` 包起来
- 新增指令 1："只依据 <课文> 内的内容出题；<示例> 内的材料绝不能用来出题"（修 R3 的风险）
- 新增指令 6："只输出一张 Markdown 表格；表格前后不要写任何说明文字"（修 R3 表格后多一段总结的问题）
- 指令 4 点名课文里的超纲词（如"箕畚""顽固""险峻"）不能出现在选项里（修 R3 的"困扰"问题）

**AI 输出**：完整输出见 `出题.md` 的"最佳示例"，节选如下。
| 题号 | 题干 | 选项 | 答案 | 解析（引用原文依据） |
|---|---|---|---|---|
| 3 | "孤儿"的意思是？ | A. 没有父母的孩子 B. 年纪很小的孩子 C. 很聪明的孩子 D. 住在山边的孩子 | A | 原文提到"邻居京城氏的寡妇有个孤儿，刚到换牙的年纪"……考点：词义推断 |
| 5 | 这个故事告诉我们什么道理？ | A. 年纪大的人应该休息 B. 坚持和决心可以克服很大的困难 C. 小孩子比大人更聪明 D. 山会自己变小 | B | ……考点：篇章主旨 |

**好在哪**
- ✓ 输出只有一张表格，前后没有多余文字，可以直接粘贴。
- ✓ 5 道题全部取材于《愚公移山》，没有用到示例里的材料。
- ✓ 正确选项的用词都在 HSK4 以内（"没有父母的孩子""用东西挡住，不能通过"）。
- ✓ 配比和解析仍然保持 R3 的水平。

**残留问题（下一轮 R5 的候选）**
- ✕ 第 2 题选项 A"继续劝阻他"用了课文原词"劝阻"（超出 HSK4）。说明点名式的禁用清单只能覆盖列出来的词，下一轮应该附上 HSK4 词表，或者改成"选项用词必须在附带的词表里"。
- ✕ 第 3 题的解析写了"结合常识可知"，没有引用上下文，词义题的解析标准还要加严，比如要求"引用的原文必须包含目标词的前后句"。

## 迭代总结

| 轮次 | 加了哪根支柱或技巧 | 修复了什么病症 | 新出现或残留的问题 |
|---|---|---|---|
| R1 | 无（零约束） | — | 简答题、语文题难度、无答案 |
| R2 | + 角色 + 格式 | 题型变成四选一，格式统一 | 题型单一、选项超纲、表格外多了文字 |
| R3 | + 要求（配比 / 难度 / 解析）+ 示例 | 配比到位，解析引用原文 | 表格后多了总结、个别选项超纲、材料和示例混在一起 |
| R4 | + 身份 / 指令 / 示例 / 上下文分区 + XML 标签（官方指南） | 只输出表格，材料和示例分清，选项超纲大幅减少 | 未点名的超纲词、词义题解析不够严 |

## 诊断与解决矩阵（本场景终版，对应课件 P10）

| 诊断维度 | 初版病症（R1/R2） | 终版药方（R3/R4） |
|---|---|---|
| 难度控制 | ✕ 语文题难度，选项里有"不置可否""困扰" | ✓ 锁定 HSK4 + 点名禁用课文超纲词（R5：附词表） |
| 题型结构 | ✕ 全是简答题，或全是细节题 | ✓ 写入强制配比：2 细节 + 2 词义 + 1 主旨 |
| 解析质量 | ✕ 没有解析，或解析只是复述 | ✓ Few-shot 示范"引用原文 + 点明考点" |
| 格式稳定 | ✕ 表格前后多出说明、正确答案被加粗 | ✓ "只输出一张表格"+ XML 分隔材料和示例 |

## 附：其他场景的迭代要点（每个场景 2 轮）

在同一套"四件套 + 分区"框架下，把出题场景学到的方法迁移到其余场景。每个场景第 2 轮修了什么，详见各模板文件里的"人工复核"。

| 模板 | R1 的主要病症 | R2 的药方 | R2 以后仍要人工把关的地方 |
|---|---|---|---|
| 教案扩展 | 4 人一组但只有 3 个角色、"感动了天地"与原文不符、结尾多了一段"特点总结" | 附课文全文 + "分组人数必须与角色数一致" + "只输出教案本身" | 板书里把被字句当成把字句的例句 |
| 生词筛查 | AI 凭记忆判等级，与课程词表矛盾（如"子子孙孙"判成六级） | 附参考词表，要求照抄；表里没有的词标"待核" | "把"的词性写错，替换说法本身可能超纲 |
| 课堂活动 | 只返回了一段摘要，没有方案内容 | "只输出活动方案本身" | 把正确的句子列成了"常见错误"，开口时间算错 |
| 语法讲练 | 只返回了一段摘要，没有材料内容 | "只输出讲练材料本身" | 偏误的"正句"本身是错句，个别答案不自然 |
| 课文分级改写 | 为了简化改动了情节（三个儿子、"邻居"智叟、神仙很感动） | 要求先列情节要点 + 输出情节自查表 | 超纲词表的"词语"栏填成了拼音，漏标声调 |
| 生词卡片 | juéding 漏标声调，"很感动人"不自然，易混词选成"感动 vs 喜欢" | 拼音规则和易混词标准配正例、反例 | 汉字中间多了空格，个别辨析写错了 |
| 口语任务卡 | 只返回了一段摘要，没有卡片内容 | "只输出任务卡和评分表" | 参考回答不自然，版块顺序不对 |

**本周最大的收获**：AI 的"格式问题"用约束几乎都能修好，"内容正确性"问题却修不干净，比如词汇等级、拼音、被字句是否自然。这部分必须由懂专业的老师把关。所以每个模板的"最佳示例"下面都附了"人工复核"。
