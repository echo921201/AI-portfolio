# 模板：课文分级改写器

> 作业 2 新增 ①（学科高频任务：把原版或高等级课文改写成低等级阅读材料）　·　版本 v2

## 提示词

```
【角色】你是国际中文教育教材编写者，熟悉《国际中文教育中文水平等级标准》各级词汇与语法。
【任务】把下面的课文改写成[目标等级]级学生能读懂的版本。
【要求】
1. 先在心里列出原文的情节要点（谁—做了什么—结果），改写时一条都不能改变：人物身份、人物关系、谁说了什么、谁有什么感受、事情的先后顺序都要和原文一致；不增加原文没有的情节
2. 词汇控制在[目标等级]及以下；专有名词（人名）保留，地名能省则省
3. 句子短：每句不超过20个字；多用"因为……所以……""虽然……但是……"等[目标等级]句式
4. 全文[字数范围]字
5. 输出结构固定：一、改写后课文 二、保留的超纲词表（表格：词语 | 拼音 | 英文释义 | 为什么保留）三、情节自查表（表格：原文情节 | 改写后句子 | 是否一致）四、改写说明（3条以内，写删了什么、换了什么）
6. 拼音每个音节都标声调，专有名词首字母大写
【示例】（改写句子示范）
原文：他苦于大山堵塞了出入的道路。
改写：大山挡住了路，他们出门很不方便。

【原课文】
[粘贴区：原课文全文]
```

## 适用说明

- **什么时候用**：手上的课文对学生来说太难，比如古文、报刊原文、高等级课文，需要改写成分级读物。
- **换等级或长度**：改 `[目标等级]`、`[字数范围]`。
- **关键设计：情节自查表**。第 1 轮 AI 为了简化，悄悄改动了情节：把"子孙中三个人"写成"三个儿子"，把"河曲智叟"写成"邻居"，把"山神怕、天帝感动"写成"神仙很感动"。第 2 轮要求它逐条列出"原文情节 → 改写句子"来自查，情节错误基本消失。
- **使用提醒**：AI 在自查表里通常全部填"一致"，这一栏不能全信。老师要拿自查表对照原文再核一遍。

## 最佳示例

> 实测：《愚公移山》白话版 → HSK3，250–350 字，第 2 轮。下面是改写后的课文和情节自查表节选。

**一、改写后课文**

北山有个老人叫愚公。他快九十岁了，住在大山前面。大山挡住了路，他很不方便。

愚公对家人说："我们一起把这个大山铲掉。这样我们可以去豫州和汉水那边。好吗？"家人都说："好。"

愚公的妻子问："你这么老，力气这么小。连小山都动不了，怎么能动大山？土放在哪里？"他们说："放在渤海边。"

愚公和儿子、孙子，还有邻居的小孩一起挖山。他们用工具把土运到渤海边。很久才去一次。

有个人叫智叟。他笑着说："你太不聪明了！你这么老，怎么能挖平山？"

愚公说："我会死。可是我的儿子活着。儿子有孩子，孩子有孙子。我们的人一直有。山也不会变大。我们怎么能挖不平？"

智叟没有话说。

后来，山神听说了。他很害怕。他告诉天帝。天帝被感动了。他派人把两座山搬走了。

从此，冀州到汉水那边，没有大山了。

**三、情节自查表（节选）**

| 原文情节 | 改写后句子 | 是否一致 |
|---|---|---|
| 妻子疑问：力气太小，土放哪里 | 愚公的妻子问："你这么老，力气这么小。连小山都动不了，怎么能动大山？土放在哪里？" | 一致 |
| 愚公带儿孙和邻居孩子一起挖 | 愚公和儿子、孙子，还有邻居的小孩一起挖山。 | 一致 |
| 山神害怕，向天帝报告 | 后来，山神听说了。他很害怕。他告诉天帝。 | 一致 |
| 天帝被感动，派人背走两座山 | 天帝被感动了。他派人把两座山搬走了。 | 一致 |

**人工复核**：
- ✓ 第 1 轮的 4 处情节错误全部修正：
  - 山神是"害怕"，被感动的是天帝。
  - 智叟不再写成"邻居"。
  - 挖山的人是儿孙。
  - "很久才去一次"对应原文的"冬夏换季才往返一次"。
- ✓ 句子短，基本都是 HSK3 词汇。
- 仍需人工改：
  - 超纲词表的"词语"一栏填成了拼音，应该填汉字。
  - "Hànshui"漏了声调，应为 Hànshuǐ。
  - "我们怎么能挖不平？"不自然，可以改成"为什么挖不平呢？"。
  - "铲"可能超出 HSK3，可以换成"挖"。
