# 模板：口语任务卡设计器

> 作业 2 新增 ③（学科高频任务：设计口语练习和测评用的任务卡）　·　版本 v2

## 提示词

```
【角色】你是国际中文教育口语课教师，熟悉HSK口试（HSKK中级）的任务类型。
【任务】围绕话题"[话题]"设计一套口语任务卡，学生为[HSK等级]水平。
【要求】
1. 共3张卡，难度递进：A卡 回答问题（3个问题）/ B卡 情景描述（给出情景，学生说1分钟）/ C卡 两人角色扮演（写清两个角色各自的任务）
2. 每张卡固定5项：任务说明（写给学生看）/ 准备时间 / 说话时间 / 必用词语（3—4个，[HSK等级]以内）/ 参考回答（80字以内）
3. 所有写给学生的文字只用[HSK等级]以内词汇
4. 最后附一张评分表（Markdown表格）：维度 | 3分 | 2分 | 1分，维度为：内容完整 / 语言准确 / 流利度 / 必用词使用
5. 只输出任务卡和评分表，不写其他说明或总结
【示例】（A卡问题示范）
问题1：你有没有坚持做过一件很难的事？请说一说。
```

## 适用说明

- **什么时候用**：口语课练习、期中口试，或者课后的"说一说"作业。
- **换话题或等级**：改 `[话题]`、`[HSK等级]`。话题最好和刚学的课文相关，比如《愚公移山》对应"坚持"。
- **关键设计**：第 1 轮只返回了一段摘要"已完成……"，没有卡片内容。第 2 轮加了第 5 条"只输出任务卡和评分表"，就能拿到完整、可打印的卡片。这条规则后来也加进了课堂活动和语法讲练的模板。
- **使用提醒**：参考回答要人工核对是否自然。准备时间和说话时间可以按考试要求调整。

## 最佳示例

> 实测：话题"坚持"，HSK4，第 2 轮。下面节选 C 卡和评分表。

#### C卡 - 两人角色扮演

**任务说明**
和你的同学一起进行对话。看清两个角色的任务，用中文说1-2分钟。

**准备时间**　1分钟
**说话时间**　1-2分钟
**必用词语**　坚持、困难、鼓励、成功

**角色A（学生）**：你最近学习很困难，想放弃了。请告诉老师你的想法。
**角色B（老师）**：你的学生想放弃了。请鼓励他继续坚持，给他信心。

**参考回答**
学生："老师，我学习很困难，想放弃了。" 老师："不要放弃。我相信你能成功。坚持下去。"

#### 评分表

| 维度 | 3分 | 2分 | 1分 |
|------|-----|-----|-----|
| 内容完整 | 内容清楚完整，回答全面，信息充分 | 内容基本清楚，信息不够完整 | 内容不清楚，信息不足 |
| 语言准确 | 语法和词汇正确，基本没有错误 | 有少数语法或词汇错误，但能理解 | 有很多错误，影响理解 |
| 流利度 | 说话流利自然，速度适当，停顿少 | 说话基本流利，有一些停顿 | 说话不流利，停顿多 |
| 必用词使用 | 正确使用全部必用词语 | 使用大部分必用词语，有1个未用 | 使用不足一半必用词语 |

**人工复核**：
- ✓ 三张卡难度递进，5 项内容齐全，评分表可以直接用。
- 可改进：
  - A 卡的参考回答"感到很成功"不自然，应为"觉得很有成就感"或"很高兴"。
  - B 卡的必用词"梦想"需要查一下是否在 HSK4 以内。
  - B 卡把"参考回答"放在"情景"前面，顺序不对，应该先写情景。
  - C 卡的参考回答很短，只有 30 多字，不够做示范。
