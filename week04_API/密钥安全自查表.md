# W4 密钥安全自查表

> 依据第4次课讲义第四节「密钥安全铁律（一票否决项）」逐项打钩。密钥泄露＝别人用你的钱，公开仓库上爬取密钥的机器人是分钟级的。

| 自查项 | 是否达标 | 说明 |
|---|---|---|
| ☐ .env 文件存在且只在本机（未被提交、未发群） | ☑ 已核对 | .env 只在本地磁盘，`git ls-files` 确认未被提交 |
| ☐ 代码里没有任何形如 `sk-xxxx` 的字符串 | ☑ 已核对 | 已检索全部 .py/.md 文件，无 sk- 密钥字样 |
| ☐ `git status` 输出中不含 .env | ☑ 已核对 | 提交前 `git status` 未出现 .env |
| ☐ 截图/录屏里看不到完整密钥 | ☐ 需自己确认 | 演示时用编辑器遮住密钥，或只显示前 4 位 |
| ☐ 若已泄露：立刻到平台后台吊销该密钥并重新生成 | ☐ 需自己确认 | 万一泄露，不要只删仓库文件，要去平台后台作废并换新 |

## 提交前自查清单（复制到终端跑一遍）

```
git status            # 输出里不应出现 .env
git ls-files | findstr .env   # 应为空
```

四项硬规矩：不写进代码、不进截图/录屏、不进聊天记录、不进仓库。
