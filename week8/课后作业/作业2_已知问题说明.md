# 作业2：README 里“已知问题”为什么要诚实写（约 200 字）

一开始我不太想写“已知问题”，觉得等于把自己没做好的地方摆出来给老师看。后来跑演示才明白，这东西不是自我检讨，是给别人省时间。

我这次实测就踩到了：知识库只放了一个等级标准节选，问把字句、问愚公移山，助手要么答“资料中未提及”，要么自己编，甚至把《愚公移山》说成孔子的作品；HSK4 词汇量标准是累计 3245，它先后给了我“3000 个左右”和“1000 个左右”两个数。这些如果我不写，下一个人照着 README 装好、跑起来，会以为是自己环境配错了，白折腾半天。写清楚了，他一眼就知道是知识库范围的问题，不是安装的问题。

反过来，藏着这些问题也没用。代码一跑就露馅，而且我连问题出在哪都说不清，更显得没真跑过。
