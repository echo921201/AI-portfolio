# 演示记录 answer_log

环境：Win11 + Python 3.11.9；Ollama 本地跑 qwen2.5:0.5b，嵌入用 nomic-embed-text；知识库是 data/等级标准节选.txt。
跑法：进 week8 目录，python assistant_v1.py。

## 1. 把字句的教学难点有哪些

- 模式：use_rag=True
- 引擎：prefer=local
- 输出摘要：列了 8 条，说是词汇理解、句型结构、语境理解、句法结构、语法知识、模仿练习、情感体验、语法实践。
- 点评：不太对。这 8 条更像学习方法，不像教学难点；而且好几处把“把字句”写成了“字句”。知识库里本来就没有把字句的内容，检索不到只能靠模型自己编。

## 2. HSK4 词汇量要求是多少

- 模式：use_rag=True
- 引擎：prefer=local
- 输出摘要：答“HSK4 的词汇量要求是 1000 个左右，具体要看不同的考试和测试标准”。
- 点评：数字错了。库里写的是中等四级新增 1000、累计 3245，模型把“新增”当成“总量”了。资料检索到了但没读准。

## 3. 《愚公移山》可以设计什么课堂活动

- 模式：use_rag=True
- 引擎：prefer=local
- 输出摘要：先简单讲了愚公移山的故事，然后给了 8 条活动：角色扮演、小组讨论、绘画故事、故事剧表演、智慧问答、角色扮演（重复）、故事竞赛、团队合作游戏。
- 点评：这次没瞎编，故事讲得对。但这篇课文也不在知识库里，答案全靠模型自己的知识，没有出处；“角色扮演”还写了两遍。

## 4. 同一问题开关对比（compare_rag.py）

- 问题：把字句的教学难点有哪些
- 模式：use_rag=True / False 各跑一次
- 引擎：prefer=local
- 输出摘要：开 RAG 讲词语和句式的关系、音形义、语法结构；关 RAG 给出词汇量积累、句式语法、句意理解、语境理解这类泛泛的说法，也把“把字句”读成“字句”。
- 点评：两种都挺空，说明问题不在开不开 RAG，是知识库里没这块内容。不过开关确实是起作用的，同一份代码走两条路，回答不一样。

## 几点体会

1. 知识库有多少料，助手就有多少底气。三个问题只有 HSK4 在库里，还答错了。
2. 检索到了不等于答对了。第 2 题资料就在手上，模型还是没把 3245 说出来。
3. 0.5b 模型不太稳。同一套代码同一句话，我这边先后跑过两次，第一次是“资料中未提及”和“3000 个左右”，第二次才是上面记的这些。
