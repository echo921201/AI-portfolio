# 三者辨析（课上互查用，各 20 字以内）

| 名词 | 哪一侧 | 一句话（20 字内） |
|---|---|---|
| Function Calling | **模型侧**的机制 | 模型只说调哪个函数、给什么参数，不执行 |
| MCP | **工具侧**的协议 | 规定工具怎么被发现、怎么被调用 |
| 普通 API 调用 | **程序侧**的请求 | 程序员写死调哪个接口、传什么参数 |

## 展开版（W9 作业 3 里写的那版，供对照）

- **Function Calling**：模型侧的机制。模型自己不会执行任何东西，只输出「我要调哪个函数、参数是什么」，执行权在程序手里——W9 手写的那 60 行循环就是它的最小实现。
- **MCP**：工具侧的协议。规定「工具长什么样、怎么被发现、怎么被调用」，让不在本机的工具也能用统一接口挂到任何支持 MCP 的模型上。
- **普通 API 调用**：程序侧的请求。我们写代码发 HTTP 请求、拿 JSON 响应，调哪个接口、传什么参数都是程序员写死的，模型不参与决定。

## 一句话串起来

普通 API 是「人写死的调用」，Function Calling 是「模型决定调什么」，MCP 是「把工具标准化，让别人的工具也能被模型发现和使用」。
