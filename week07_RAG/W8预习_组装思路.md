# 第8周预习：项目怎么组装

（作业3：想想第8周怎么把 rag_qa.py 和 llm.py 拼成一个能演示的问答助手）

## 现在手里有什么

- llm.py：统一入口，LLM().ask(问题, prefer="local"/"api")，本地和云端都能调，一个挂了自动切另一个；
- rag_qa.py：基于资料回答，内部先检索再生成；
- data/等级标准节选.txt：知识库语料。

现在这俩是分开的脚本，第8周就是把它俩拼成个助手：输入一个问题，能选走本地还是云端，能答，还能告诉人答案是从哪段资料来的。

## 我大概想这么搭

```
week08_问答助手/
├── main.py              入口：循环读输入，调 qa()
├── llm.py               从 week06 拿过来用
├── rag_qa.py            从 week07 拿过来用
├── weekpath.py          复用，管 import 和 .env
├── data/等级标准节选.txt
├── chroma_db/           向量库，建过一次就不用重来，不进 git
└── README.md            写怎么跑、演示什么
```

## 要补的东西

1. 一个 qa() 主函数，把检索和生成串起来，外面就调这一个口；
2. 选引擎的开关，复杂题默认走云端，简单题走本地，顺便能演示双向回退；
3. 答案带上出处片段，这样能说"这个数字来自总表哪一行"；
4. 多轮追问，把上一轮的答案拼进下一轮上下文（讲义作业1的进阶项）；
5. 入口做个 while 循环，输入"退出"就停。

## 原则

llm.py 和 rag_qa.py 的核心逻辑不动，只在外面套一层组装和入口，复用前两周的东西，符合"一条主线贯穿"。
